# draco

- 量化：将浮点数数据转换为整数，减少存储空间，同时选择合适的精度以保持视觉质量
- 熵编码：使用霍夫曼编码等技术，对频繁出现的数据值使用更少的比特位进行编码，进一步提高压缩比。
- 几何压缩：针对顶点坐标、法线和纹理坐标等数据，优化其存储方式。
- 拓扑编码：通过分析模型的连接关系，减少存储冗余。例如，使用 Edgebreaker 算法对网格拓扑进行编码。
- 基于 KD-tree 的编码器：重排点以实现最佳压缩

- `etc1s`：编码体积较小
