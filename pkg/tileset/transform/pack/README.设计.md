
一个背负着失忆诅咒的少年，凭借一本写给自己的“遗书”和“拔剑术”，踏上了穿越千年时光、追寻自我真相与诅咒起源的孤独旅程。


第一卷：遗忘与苏醒（新的12年开始）

开端：主角在西方某城醒来，身边只有葫芦和“书”。书中指示他前往“学者之城”阿卡尼亚，寻找关于女巫与记忆水晶的线索。他一边学习当地语言、熟悉世界，一边凭借“书”中的剑术训练法，重新锻炼出那惊鸿一瞥的“拔剑术”。

## 装备

拔剑术：速度奇快，快到剑看起来就没有出鞘过。

葫芦：空间宝物，大概有10m³大小。

## 遗书

十二年后，你我于此重逢。

你此刻手握的，是我全部的时间。

我追索记忆的残影至此未果，但确信两件事：我们来自东方；遗忘非终点，而是每次寻找的起点。

若感孤独，请望向剑柄的磨损处——那是千年旅途中，“我们”曾存在过的唯一证据。

葫芦里有路费、地图与日志
